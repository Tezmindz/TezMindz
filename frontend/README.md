# TezMindz Frontend Directory

This folder contains all the frontend assets and templates for the TezMindz application.

## Directory Structure:
- `templates/` — All Django HTML templates (UI views, components, dashboards, modals, games).
- `static/` — All CSS stylesheets, client-side JavaScript, game engines, audio, and visual assets:
  - `static/css/styles.css` — Global responsive design & utility classes.
  - `static/js/store.js` — Client-side state manager and user storage.
  - `static/games/` — 3D game engines, canvas renderers, and construction components.

## How to Work:
1. Edit HTML layouts inside `templates/`.
2. Edit styles & animations in `static/css/styles.css`.
3. Test changes locally by starting the server with `python manage.py runserver`.
